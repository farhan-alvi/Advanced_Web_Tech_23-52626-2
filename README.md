# Advanced Web Technology

This repository contains practical projects and coursework developed as part of the Advanced Web Technology course. It explores modern web development through hands-on implementation, with a focus on TypeScript, JavaScript, Node.js, NestJS, RESTful APIs, and structured application architecture.

## Key Concepts

- **RESTful APIs:** Enable communication between clients and servers using HTTP methods such as `GET`, `POST`, `PUT`, `PATCH`, and `DELETE`.
- **Backend Development:** Covers server-side logic, request handling, routing, and application structure.
- **TypeScript and JavaScript:** Languages used to build maintainable and interactive web applications.
- **Node.js and NestJS:** Tools for developing structured, modular, and scalable backend applications.
- **Web Application Architecture:** Emphasizes separation of concerns, reusable components, and maintainable code.
- **Version Control:** Uses Git and GitHub to track changes and manage project development.

## Quick Notes

### HTTP Methods

- **GET:** Retrieves data from a server.
- **POST:** Submits data to create a resource.
- **PUT:** Replaces or updates a resource.
- **PATCH:** Partially updates an existing resource.
- **DELETE:** Removes a resource.

### NestJS Architecture

- **Controllers:** Handle incoming requests, define routes, and return responses.
- **Services:** Contain application logic and perform operations requested by controllers.
- **Modules:** Organize related components into logical sections in NestJS.
- **Dependency Injection:** Allows NestJS to provide required services and dependencies to other components.
- **Middleware:** Processes requests before they reach route handlers and can be used for tasks such as logging.

### Web Development Fundamentals

- **HTTP Status Codes:** Indicate the result of a request, including successful operations and client or server errors.
- **API Testing:** Tools such as Postman help test endpoints by sending HTTP requests and inspecting responses.
- **JSON:** A common data format for exchanging information between clients and servers.
- **Type Safety:** TypeScript helps detect certain errors during development through its type system.
